도입 전 우려하실 부분과, 준비된 대응입니다

Q1제공사가 단가 · 정책을 바꾸면?

멀티 벤더 구조로 특정 제공사에 의존하지 않습니다. 크레딧 단가는 학기 단위 조정 조항으로 계약에 명시합니다.

Q2수업 중 API 한도가 초과되면?

API 키 풀 자동 전환과 상태 모니터링으로 수업 중 서비스 중단 없이 운영합니다.

Q3학생이 유해 콘텐츠를 생성하면?

제공사 안전 정책과 자체 모더레이션으로 이중 차단하고, 전 생성 기록을 로그로 보존해 사후 추적이 가능합니다.

Q4개인정보가 유출되지 않을까?

최소 수집 원칙 · PBKDF2-SHA256 해싱 · HTTPS 암호화 · 학교별 테넌트 분리로 데이터가 섞이지 않습니다.

Q5내년 예산이 줄어들면?

RISE · AID 등 복수 재정지원사업 연계로 재원을 다변화하고, 크레딧 규모는 예산에 맞춰 탄력 조정합니다.

Q6도입까지 얼마나 걸리나요?

클라우드 구축은 1주면 가능합니다. 학기 시작 4주 전에 계약하면 당학기에 바로 적용되며, 보안 요건에 따라 온프레미스 구축도 선택할 수 있습니다.
