코드를 몰라도 LLM과 대화하며 제작에 필요한 프로그램을 직접 만들고, 반복 작업을 줄이거나 결과물 품질을 끌어올립니다. 정해진 도구를 배우는 대신 스스로 도구를 만드는 방법을 익혀, 교육이 끝난 뒤에도 새로운 업무에 바로 적용합니다.

개발 경험이 없는 기획·제작·행정 인력이 실제로 동작하는 도구를 만들어 팀 업무에 바로 사용했습니다.

  • 산출물 — 스토리보드 생성기 · 이미지·영상 생성 스튜디오
  • Claude · Cursor 등으로 요구사항을 대화로 구체화
  • 문법 암기가 아닌 문제 정의와 검증 — 비개발 인력도 완주
  • 코드를 몰라도 동작하는 서비스를 직접 만들어 팀에 배포

ComfyUI 중심 사내 AI 전문 인력 양성

생성형 AI는 하루, 일주일, 한 달 단위로 바뀝니다. 외부 플랫폼에만 의존하지 않고 변화를 직접 팔로업하며 사내 시스템을 구축·운영할 인력을 키웁니다. 핵심은 생성 과정을 직접 설계하는 오픈소스 도구 ComfyUI입니다.
